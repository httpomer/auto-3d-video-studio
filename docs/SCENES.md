# Scene template reference

Generated by `npm run catalog` — do not edit by hand.

## `ai_core`

Abstract AI "brain" hero: a luminous energy core inside slowly rotating gyroscope rings, a shell of orbiting particles and data streams spiralling inward, above a lit pedestal on the reflective floor. Calm enough to sit behind big title text (use the "left"/"right" framings to leave room for it).

| param | meaning |
|---|---|
| `intensity` | 0..1 energy level — core brightness, light and particle glow (default 0.7, tweens between continued shots) |
| `rings` | Number of gyroscope rings, 1–5 (default 3) |
| `label` | Optional short label shown under the core (e.g. a model name) |
| `streams` | 0..1 amount of inward data streams (default 0.8, tweens) |

**Framings:** `wide`, `hero`, `close`, `low`, `top`, `orbit_far`, `right`, `left`

**Sample params:**
```json
{"intensity":0.8,"rings":3,"label":"FOUNDATION MODEL"}
```

## `backdrop`

Abstract 3D environment for titles, chapter cards, quotes and big numbers (pair it with title / chapter / stat / quote overlays). Styles: "wave" (flowing field of light points), "galaxy" (slow swirling particle disc with a glowing core), "pillars" (a city of rising light columns), "tunnel" (flying through rings of light — good for hooks and transitions).

| param | meaning |
|---|---|
| `style` | "wave" \| "galaxy" \| "pillars" \| "tunnel" (default "wave") |
| `speed` | Motion speed multiplier (default 1) |
| `intensity` | 0..1 brightness / energy (default 0.7, tweens between continued shots) |

**Framings:** `wide`, `low`, `hero`, `top`, `side`

**Sample params:**
```json
{"style":"wave"}
```

## `bar_chart`

Data-driven 3D bar chart on a reflective studio floor. Bars grow from zero one after another, value labels count up above each bar, category labels sit in front, and one bar can be highlighted (the others dim). Heights are exactly proportional to the data.

| param | meaning |
|---|---|
| `data` | [{label, value, color?}] — 2 to 12 bars (max 16). Heights are proportional to value; negative values drop below the baseline. |
| `prefix` | Text before each value, e.g. "$" |
| `suffix` | Text after each value, e.g. "B" or "%" |
| `decimals` | Decimal places for value labels (default 0) |
| `compact` | true → 1.2K / 3.4M / 5.6B / 7.8T formatting of raw numbers |
| `highlight` | Index of the bar to emphasise (accent glow, others dim). Omit or -1 for none. Tweens when a continued shot changes it. |
| `title` | Optional chart title shown top-left of the back grid |
| `subtitle` | Optional small line under the title (unit, source period ...) |
| `maxValue` | Optional top of the value axis (default: rounded-up max of the data) |
| `cues` | { grow: seconds when bars start growing (default 0.3), highlight: seconds when the highlight kicks in (default: after growth) } — shot-local times, may be "@word" in the storyboard |

**Framings:** `wide`, `front`, `left`, `right`, `hero`, `top`, `low`, `last`

**Sample params:**
```json
{"title":"Data-center revenue","subtitle":"USD billions, fiscal year","prefix":"$","suffix":"B","decimals":1,"highlight":4,"data":[{"label":"FY21","value":6.7},{"label":"FY22","value":10.6},{"label":"FY23","value":15},{"label":"FY24","value":47.5},{"label":"FY25","value":115.2}]}
```

## `bubbles`

Scale comparison with spheres: each item is a glossy sphere whose cross-section area is proportional to its value (so sizes are honest), lined up left→right with name and value labels. Use for market caps, revenue by company, model sizes, "X is bigger than A+B+C".

| param | meaning |
|---|---|
| `items` | [{ label, value, color? }] — 2 to 7 items, shown in the order given |
| `prefix` | Value prefix, e.g. "$" |
| `suffix` | Value suffix, e.g. "B" |
| `decimals` | Decimals in value labels (default 0) |
| `compact` | true → 4200000000000 shows as 4.2T |
| `highlight` | Index to emphasise (-1 = none); tweens between continued shots |
| `cues` | item0, item1, … — shot-local times at which each sphere grows in |

**Framings:** `wide`, `front`, `hero`, `low`, `top`, `small`

**Sample params:**
```json
{"items":[{"label":"NVIDIA","value":4300},{"label":"TSMC","value":1100},{"label":"Broadcom","value":1300},{"label":"AMD","value":260},{"label":"Intel","value":100}],"prefix":"$","suffix":"B","highlight":0}
```

## `candles`

Stock candlestick chart in 3D. Candles form one after another left→right (green/up = theme accent, red/down = theme danger) with volume bars along the floor, a moving-average ribbon and a live last-price line + label. Use real OHLC data or let it generate a seeded illustrative series (label illustrative data as such in narration).

| param | meaning |
|---|---|
| `candles` | [[open, high, low, close, volume?], ...] real OHLC data (2–160 candles). If omitted an ILLUSTRATIVE series is generated from count/seed/trend. |
| `count` | Number of generated candles (default 56) |
| `seed` | Seed for the generated series |
| `trend` | 'up' \| 'down' \| 'volatile' \| 'crash' for the generated series |
| `startPrice` | First open of the generated series (default 100) |
| `ticker` | Ticker / name shown top-left, e.g. "NVDA" |
| `prefix` | Price prefix, e.g. "$" |
| `decimals` | Price decimals (default 2) |
| `showChange` | false to hide the running % change under the ticker |
| `drawDur` | Seconds for all candles to appear (default ≈ 70 % of the shot) |
| `cues` | { draw: seconds when candles start forming (default 0.4) } — shot-local |

**Framings:** `wide`, `front`, `chase_start`, `chase_end`, `low`, `end`, `top`

**Sample params:**
```json
{"ticker":"NVDA","prefix":"$","trend":"up","seed":4,"count":56}
```

| param | meaning |

## `city`

Financial-district skyline at night: glass skyscrapers with lit windows, wet reflective streets, traffic light trails and haze. `growth` makes the towers rise out of the ground (economy / company growth metaphor); an optional accent-lit `hero` tower with a label stands for the market leader; `tickers` float labels over other towers.

| param | meaning |
|---|---|
| `seed` | Layout seed (same seed → same city) |
| `density` | 0.2..1 share of lots that hold a tower (default 0.85) |
| `growth` | 0..1 how far the towers have risen (default 1 = fully built). Tweens between continued shots. |
| `growthFrom` | Starting growth for the first shot, e.g. 0 to watch the city rise |
| `hero` | { label, sub?, height? } accent-lit tallest tower at the centre with a HUD label (height in scene units, default 18; other towers reach ~12) |
| `tickers` | [{label, value?}] up to 6 floating labels over other tall towers (e.g. competitors / tickers) |
| `cues` | { grow: seconds when the growth tween starts (default 0.4) } — shot-local |

**Framings:** `wide`, `aerial`, `street`, `hero`, `flyover_start`, `flyover_end`, `skyline`, `top`

**Sample params:**
```json
{"seed":3,"growthFrom":0,"growth":1,"hero":{"label":"NVIDIA","sub":"$4.4T market cap"},"tickers":[{"label":"MSFT","value":"$3.9T"},{"label":"AAPL","value":"$3.6T"},{"label":"GOOGL","value":"$2.5T"}]}
```

## `cores_compare`

CPU vs GPU explainer. Two platforms get the same job (a wall of 1,296 task tiles that form a picture). Left: a few large cores light up one after another and fill the wall tile by tile. Right: a grid of ~1,000 tiny cores fires all at once and finishes in a couple of cycles. Live task counters per side.

| param | meaning |
|---|---|
| `leftLabel` | Title of the left side (default "CPU") |
| `rightLabel` | Title of the right side (default "GPU") |
| `leftCores` | Number of large cores on the left (2-16, default 8) |
| `rightGrid` | Tiny cores per side on the right: N×N grid (8-40, default 32 → 1,024 cores) |
| `mode` | 'both' \| 'left' \| 'right' — which side is in focus (the other dims). Tweens when a continued shot changes it. |
| `speed` | Work speed multiplier for both sides (default 1) |
| `cues` | { start: seconds } or { left: seconds, right: seconds } — when each side starts working (first shot of the scene only; default 1.6 s) |

**Framings:** `wide`, `left`, `right`, `top`, `low`, `left_cores`, `right_cores`, `angle`

**Sample params:**
```json
{"leftLabel":"CPU","rightLabel":"GPU","leftCores":8,"rightGrid":32,"mode":"both"}
```

## `data_flow`

A left-to-right pipeline of 2–6 labelled stages (e.g. Data → Training → Model → Inference → Apps). Each stage is a small 3D object on a lit pedestal; glass tubes between them carry streams of glowing particles. Stages can reveal one by one and one stage can be emphasised.

| param | meaning |
|---|---|
| `stages` | Array of 2–6 stages: { label, sub?, icon?, color? }. icon ∈ cube \| stack \| cylinder (database) \| chip \| sphere \| screen \| gear. color defaults to the theme accents. |
| `visible` | How many stages are shown (default all). Tweens in continued shots, so 2 → 5 reveals the rest one by one. |
| `active` | Index of the emphasised stage (others dim slightly); -1 / omitted = none. Tweens. |
| `flow` | 0..1 particle density in the tubes (default 0.8, tweens) |
| `reveal` | "sequential" (default: stages build up one after another in the first ~2 s) \| "all" (appear together) |
| `cues` | stage0 … stage5 — shot-local time at which that stage appears (first shot / newly visible stages) and briefly pulses |

**Framings:** `wide`, `left`, `right`, `travel_start`, `travel_end`, `top`, `close`, `low`

**Sample params:**
```json
{"stages":[{"label":"Data","sub":"Text, images, video","icon":"cylinder"},{"label":"Training","sub":"GPU clusters","icon":"chip"},{"label":"Model","sub":"Billions of weights","icon":"sphere"},{"label":"Inference","icon":"stack"},{"label":"Apps","icon":"screen"}],"active":2}
```

## `donut`

Market-share / breakdown donut. Bevelled 3D ring segments sweep in clockwise from the top one after another; percentages (exactly value ÷ total) and names sit beside each segment; the highlighted segment lifts and slides outward with a glow; a big value sits in the centre.

| param | meaning |
|---|---|
| `data` | [{label, value, color?}] — 2 to 8 segments recommended (max 12). Angles are exactly proportional to value. |
| `highlight` | Index of the segment to pull out and light up (omit / -1 for none). Tweens when a continued shot changes it. |
| `centerLabel` | Big text in the middle of the ring, e.g. "92%" or "$4.2T" |
| `centerSub` | Small line under it, e.g. "of AI accelerators" |
| `decimals` | Decimals for the percentages (default 0) |
| `showValue` | true → also show each raw value after the name (uses prefix/suffix/compact/valueDecimals) |
| `prefix` | Value prefix |
| `suffix` | Value suffix |
| `compact` | K/M/B/T value formatting |
| `valueDecimals` | Decimals for raw values (default 0) |
| `cues` | { sweep: seconds when segments start sweeping in (default 0.3), highlight: seconds when the highlight lifts (default: after the sweep) } — shot-local |

**Framings:** `wide`, `hero`, `top`, `close`, `low`, `side`

**Sample params:**

## `globe`

Dotted-land globe with atmosphere glow: labelled location pins, animated great-circle arcs with travelling pulses, slow rotation. The globe turns so a chosen region faces the camera. Use for supply chains, global markets, data routes, geopolitics.

| param | meaning |
|---|---|
| `points` | [{ name, lat, lon, color?, label?, dx?, dy? }] — pins with HUD labels. color = theme key (accent\|accent2\|warm\|danger) or hex; dx/dy nudge the label in px to separate neighbours. Fixed by the first shot of the scene. |
| `arcs` | [[fromName, toName], ...] — arcs drawn one after another between named points. Fixed by the first shot of the scene. |
| `focus` | { lat, lon } — rotate the globe so this spot faces the camera; a continued shot with a new focus turns the globe smoothly. Omit for free rotation. |
| `spin` | Free rotation speed in rad/s when no focus is set (default 0.1) |
| `labels` | true\|false show pin name labels (default true) |
| `cues` | { arcs: seconds } start of the arc sequence, or per arc { arc0: s, arc1: s, ... } (shot-local seconds) |

**Framings:** `front`, `wide`, `close`, `left`, `right`, `high`, `low`, `horizon`

**Sample params:**
```json
{"points":[{"name":"Netherlands","lat":51.4,"lon":5.5,"color":"accent2"},{"name":"Taiwan","lat":24.8,"lon":121,"color":"warm"},{"name":"Japan","lat":35.7,"lon":139.7,"color":"accent2"},{"name":"South Korea","lat":37.5,"lon":127,"color":"accent2"},{"name":"USA","lat":37.4,"lon":-122,"color":"accent"}],"arcs":[["Netherlands","Taiwan"],["Japan","Taiwan"],["South Korea","Taiwan"],["Taiwan","USA"]],"focus":{"lat":30,"lon":135}}
```

## `line_chart`

Growth-over-time chart in 3D (stock price, revenue, users ...). A glowing line draws itself left→right with a bright head and live value label, a translucent area fills in beneath, axis labels and optional event markers pop as the head passes. Up to 3 series. Values are plotted exactly (zero-based axis unless yMin/logScale is set).

| param | meaning |
|---|---|
| `series` | [{label?, color?, data: [numbers]}] — 1 to 3 series (each ≥ 2 points). Shorthand: `data: [numbers]` for one series. |
| `xLabels` | [strings] labels along the time axis (same length as the data, or any shorter list spread evenly) |
| `prefix` | Text before values, e.g. "$" |
| `suffix` | Text after values, e.g. "B" |
| `decimals` | Decimal places (default 0) |
| `compact` | true → K/M/B/T formatting |
| `title` | Optional chart title (top-left) |
| `subtitle` | Optional small line under the title |
| `drawDur` | Seconds the line takes to draw (default ≈ 70 % of the shot). For chase_start→chase_end camera moves set it close to the shot length. |
| `markers` | [{index, label, series?}] event markers that pop when the head passes data index `index` |
| `logScale` | true → logarithmic value axis (all values must be > 0) |
| `yMin` | Optional axis minimum (default 0 — honest zero-based axis) |
| `yMax` | Optional axis maximum |
| `cues` | { draw: seconds when the line starts drawing (default 0.4) } — shot-local |

**Framings:** `wide`, `front`, `chase_start`, `chase_end`, `end`, `low`, `top`

**Sample params:**
```json
{"title":"Share price","subtitle":"USD, split-adjusted","prefix":"$","decimals":0,"xLabels":["2019","2020","2021","2022","2023","2024","2025"],"series":[{"label":"NVDA","data":[6,13,29,15,49,134,177]}],"markers":[{"index":3,"label":"ChatGPT launch"},{"index":5,"label":"AI boom"}]}
```

| `lossEnd` | Loss value shown at the minimum (default 0.03) |

## `neural_network`

A 3D neural network: layers of glass-orb neurons joined by glowing filaments. Activation pulses sweep forward layer by layer and neurons flash as signals arrive. In training mode a dimmer warm error wave also travels backward.

| param | meaning |
|---|---|
| `layers` | Array of neuron counts per layer, e.g. [4,7,7,5,2] (2–8 layers, 1–12 neurons each) |
| `labels` | Optional array of names shown under each layer, e.g. ["Input","Hidden","Hidden","Hidden","Output"] (use "" to skip one) |
| `activity` | 0..1 how many neurons / connections fire per wave (default 0.7, tweens between continued shots) |
| `mode` | "inference" (default, forward pulses only) \| "training" (adds a backward warm error wave) |
| `highlightLayer` | Index of a layer to emphasise (brighter, larger); omit or -1 for none (tweens) |
| `layout` | "column" (default, classic diagram with depth stagger) \| "ring" (neurons of each layer on a circle) |
| `speed` | Pulse speed multiplier (default 1) |

**Framings:** `wide`, `front`, `side`, `close`, `top`, `output`, `low`

**Sample params:**
```json
{"layers":[4,7,7,5,2],"labels":["Input","Hidden","Hidden","Hidden","Output"],"activity":0.8,"mode":"inference"}
```

## `token_stream`

How a language model predicts text: a column of input word tokens flies in from the left, flows through a stack of translucent transformer layers whose attention lines light up layer by layer, and predicted output tokens emerge one at a time on the right with the newest highlighted.

| param | meaning |
|---|---|
| `input` | Array of input tokens (1–8 short words), e.g. ["The","future","of","computing","is"] |
| `output` | Array of predicted tokens (1–6) that emerge one by one, e.g. ["accelerated","."] |
| `layers` | Number of transformer layers in the stack, 2–10 (default 6) |
| `speed` | Time scale of the whole animation (default 1; first output appears ~3.2 s / speed, then one every ~1.7 s / speed) |
| `cues` | emit — shot-local time at which the FIRST output token emerges (later tokens follow automatically) |

**Framings:** `wide`, `input`, `stack`, `output`, `top`, `low`, `through`

**Sample params:**
```json
{"input":["The","future","of","computing","is"],"output":["accelerated","."],"layers":6}
```
